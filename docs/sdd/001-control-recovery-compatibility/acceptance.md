## 全局验收场景与证据要求

| 场景 | 最低检查 |
|---|---|
| 两节点统一控制 | A操作B、B故障接管、旧owner恢复、断网后结果未知与重查、相同请求重复路由；全局权限撤销立即按策略生效 |
| 登录保持 | 刷新、新标签页、过期、退出、跨节点路由、控制器重开、权限变更、CSRF和身份冲突；登录恢复不发出额外任务动作 |
| 目标事务跳过 | 单事务跨多表、指定一个/多个目标、重复请求、回执提交后ACK丢失、旧代次/旧错误版本、已实际提交的事务、审计不可写 |
| 采集/解码故障 | 有/无完整边界、已知/未知影响、原日志不可读、日志被清理、错源、全部相关订阅；不支持执行时显示可恢复路径 |
